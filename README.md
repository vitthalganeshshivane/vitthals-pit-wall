## 🛠️ How to Use Pit Wall

### Getting Started
1. **Clone & Install**
   ```bash
   git clone https://github.com/yourusername/pit-wall.git
   cd pit-wall
   npm install
   ```

2. **Run Locally**
   ```bash
   npm run dev
   ```
   Visit `http://localhost:5173` to see your dashboard come alive

3. **Make It Yours**
   - Open `src/components/Hero.jsx` to change the greeting name
   - Update `src/components/ColophonModal.jsx` to personalize the footer
   - Modify available years in the context file to follow different seasons

### Navigation Shortcuts
- **Click any driver** in the standings to see their full dossier
- **Click any race** in the calendar for detailed weekend results
- **Click "Circuit Info"** on any race for track history and stats
- **Use the season selector** to jump between different F1 years
